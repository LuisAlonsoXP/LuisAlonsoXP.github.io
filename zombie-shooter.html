Sobre el juego

Zombie Shooter VR es un juego de supervivencia en primera persona diseñado para Meta Quest 3S. El jugador debe eliminar oleadas de enemigos usando armas y granadas dentro de un entorno 3D totalmente inmersivo.


Fue desarrollado como proyecto personal para explorar las capacidades de Unity XR y el desarrollo de videojuegos en realidad virtual con interacción física mediante los controles del Quest.

Características

  • Múltiples tipos de enemigos con IA (zombies, arañas)
  • Sistema de rondas con dificultad progresiva
  • Física de granadas con explosión en cadena
  • Navegación de enemigos con NavMesh
  • Interacción VR con XR Interaction Toolkit
  • Build optimizado para Android (Meta Quest 3S)
  • Sistema de slots para equipamiento

Tecnologías usadas

Unity
Motor principal del juego
C#
Toda la lógica del juego
XR Toolkit
Interacción VR y controles
NavMesh
Pathfinding de enemigos
Meta Quest 3S
Plataforma objetivo
Android SDK
Build y deploy al headset
